# S3 — Optimization Strategies

| Strategy | Savings | Effort | Use Case |
|----------|---------|--------|----------|
| Intelligent-Tiering | Up to 95% | Low | Unknown access patterns |
| Lifecycle to IA/Glacier | Up to 90% | Low | Infrequent access data |
| Expiration rules | 100% | Low | Temporary/log data |
| Version cleanup | Variable | Low | Expire noncurrent versions in versioned buckets |
| Compression / dedup | Variable | Low | Compress files; remove redundant objects |
